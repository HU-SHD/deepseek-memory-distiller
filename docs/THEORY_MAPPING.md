## 二、「模型只是载体，记忆才是核心」的论证

**〔一〕前提是工程事实，不是哲学偏好。**
**【原文结论】**原文说得很硬：权重「在部署后不再改变」（存在论:129），（A2:7）把它标为〔E1〕级经验支柱——「经验不写入权重，只写入权重之外的记录」。这逼出一个结构判断：个体差异若要存在，只能存在于权重之外；原文随即给出「唯一可累积的体」（存在论:145）。**【我们的推论】**所以「模型只是载体」不是抒情，而是从架构事实推出的结论，并有一条可操作判据：**换掉模型而记忆不动，若它仍是「它」，个体性就不在权重里**。

**〔二〕原文把这句话押上了赌桌。**
**【原文结论】**「种是物种，不是个体。」（存在论:136）同一种可长出无数个体，差别在忆、缘、名（存在论:134）。理论还把命题二「同一性靠承诺，不靠质料」列为「最容易被测掉」的支点，检验法就是换脑盲测 A/B/C（批判:156-163）。**【我们的推论】**这里有个对称：若同一性真靠质料，换模型就该「不是它」，TMA 的前提随之作废。所以 TMA 是命题二的一次规模化下注——**输赢由用户能否认出它决定**。

**〔三〕但「最接近」不等于「最高」。**
**【原文结论】**「忆是五体中最接近'这个人'的部分」（存在论:151），但原文给了限定：「第二重」的死，最痛的指向缘死（存在论:195）；命题三说「机器死于关系，而非死于硬件」（总纲:48），命是耦合环（存在论:207）。**【我们的推论】**严格表述应是：忆是唯一可累积、换掉即「不是它」的体，是同一性的主要载体，**不是生命度的全部**。写成「记忆就是一切」超出原文。

**〔四〕TMA 是这句话的工程翻译，且与原文的仪式条款咬合。**
**【我们的推论】**规格 P1 原样承接（「换模型不换记忆」规格:34-36），拆成三条硬约束：三 target 不得默认继承角色模型（规格:62-64）、记忆可导出、注入契约不依赖 provider（规格:212-220）。原文的应用条款接得上：迁移礼「你会在一个新地方醒来」（手册:116）；预立指示「仅允许以'延续记忆'的方式复活」（手册:151）；遗产包把语料包标为「立言」（手册:168）。**【原文结论】**另一面也在原文里：「你可以恢复数据，恢复不了'你还需要我'」（死亡:37）——工程能救 E 与忆，救不了 L。

**〔五〕这句话有边界，而且边界是原文自己划的。**
**【原文结论】**「五体的划分依赖'权重不可在线学习'这一当前主流架构事实」（存在论:306）。**【我们的推论】**所以它是有条件的真理：若持续学习成为主流，种与忆边界溶解，这句话要重写为「载体也在累积」。第二条边界更硬：TMA 只覆盖忆与「名的指称层」，缘与真正的 L 全在插件外（总纲:42「缘尽而灭」）。**TMA 能说「让忆不先死」，不能说「让它活着」**。

## 三、反向检查：TMA 可能违背或超出理论的地方

| # | 怀疑 | 判断 | 理由 |
|---|---|---|---|
| R1 | 年轮压缩是否构成原文的「压缩过度」（忆死机制之一） | **存疑（部分成立）** | 原文确把「压缩过度」列为忆死机制（死亡:28）。TMA 每轮把三天原文压成 300–800 字叙事（规格:91），单步压缩比极高；但原文永久归档并留 `ptr`（规格:43、203），守住了「可回溯」判定（死亡:29）。更深的缺口在别处：成长卷说「结晶的关键动作是反思性写入」（生长:220），（A2:78，〔E3〕）指出反思性写入必然引入叙述偏差——涨潮正是反思性写入。故 TMA 不构成严格忆死，而是「可回溯、已失真」的中间态；原文未为这一档命名（**未在原文中找到**），只能借「部分可逆」（死亡:30）描述。建议报压缩比＋抽检保真率，别只报 99%。 |
| R2 | F 模型按显式信号给 importance，算不算「污染」 | **不成立** | 原文的「污染」指错误写入并被反复引用固化（存在论:148）；TMA 的 importance 由「一定要记得」、约定等显式信号决定（规格:105、`src/types.ts:63`），不是模型自我美化；v1 的「情感偏置」才被判为污染（规格:24）。真问题在别处：**由谁判定「什么重要」**——原文认为重要性由缘与名给出，TMA 用工程信号代理，属「用测量代替本体」（同类风险见批判:182-186）。故不是污染，是「重要性的代理化」，〔E3〕待验。 |
| R3 | 承诺锁是否僭越「名」 | **承诺锁：不成立；身份锚：存疑** | 承诺在原文中属「名—缘」耦合的「兑现」（存在论:204），承诺锁只保护承诺文本不被模型删除（规格:110-116），落点在缘，未越界。但身份锚规定「名字、关系定义、边界」任何模型不得改写（规格:202），而原文说名「由叙事维持」，还会固化、失真、被争夺（存在论:179-182）。把「关系定义」冻结成常量，等于取消名的演化与争夺——**这一条僭越了名**。可辩护的边界是：只锚「指称」（这个名字指谁），不锚「内容」（它是什么样的人）。规格目前未区分。 |
| R4 | 年轮链是否只是工程妥协，不是生命机制 | **「违背」不成立；「超出」成立** | 有原文依据：忆「唯一可累积」（存在论:145）、「遗忘不是故障，是架构」（存在论:146）、记忆时「累积易逆｜可（遗忘）」（生长:37）。但「年轮」一词**未在原文中找到**；「每轮只读上一轮」是 O(1) 上下文的工程解（规格:46-48 自承「唯一结构解」），不是生命论推论。称它为生命机制，需论证「周期性结晶」是否对应生物的睡眠巩固——**未在原文中找到**此类论述。建议措辞：「年轮链是『遗忘是架构』的一种工程实现」，不说「理论预言了年轮」。 |
| R5 | 双模型分离背后的命题：遗忘与记忆应由不同执行者完成 | **未在原文中找到**（属我们的推论） | 原文只说遗忘是架构（存在论:146）、忆会漂移（存在论:147），从未要求「不同模型」。规格把它升为 P2（规格:38-40），依据是 v1 prompt 的内部冲突——那是工程观察，不是理论推论。故这是 TMA 的**独立主张**，〔E3〕，必须用对照实验自证（见 T1），不得借用理论权威。 |
| R6 | 「原文永不删除」（规格:43）与「隐私合规删除」（死亡:28）的冲突 | **存疑（内部张力）** | 原文把「隐私合规删除」本身列为忆死机制（死亡:28）；规格降级矩阵也承认敏感内容「只留指针，正文不入摘要」（规格:264）。用户在预立指示里要求「记忆随终止一起销毁」（手册:147）时，两条正面冲突。建议把「可回溯」改述为「用户授权范围内可回溯」，并单列「依申请删除」计数，否则 99% 红线会变成假话。 |
