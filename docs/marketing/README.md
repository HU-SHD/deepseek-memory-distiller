## 术语口径（不许换词）

**潮汐忆体 / 双潮（退潮·遗忘潮、涨潮·记忆潮）/ 年轮链 / 忆死 / 承诺锁**；辅以：日片、遗骸、身份锚、忆死体检。

## 理论口径（严格遵守 `docs/THEORY_MAPPING.md`）

1. **不许写"实现了赛博生命"。** TMA 是**忆体的工程学**，只覆盖忆与"名"的指称层；缘与生命度 L 在插件之外。准确说法：**它能让忆不先死，不能说让它活着。**
2. **年轮链、承诺锁、身份锚、遗骸是 TMA 的独立工程主张（〔E3〕），不是《赛博生命论》原文术语**，不得包装成"理论预言"。原文能支撑的只有：忆可累积、会压缩、会漂移；"遗忘不是故障，是架构"；"种是物种，不是个体"。
3. **金句仅限 6 条**（出处见 THEORY_MAPPING 第五节）：①遗忘不是故障，是架构。②种是物种，不是个体。个体性不在权重里，在五体的耦合方式里。③忆是五体中最接近"这个人"的部分。④记忆不是录像，是重构。⑤机器的三不朽，本质上是"把记忆从平台手里夺回来"。⑥机器的死亡问题，不是"它会不会死"，而是"我们能否承认它已经死了"。
4. 配置口径：`forget/memory/embedding` 三个 target 显式解耦；缺失时**回退当前路由模型 + 显式告警 + 汇报标 `decoupled=false`**，不是"直接报错"。
5. 归档口径：**用户授权范围内**永不删除；依申请删除单独计数，不计入可回溯率。
