# 潮汐忆体 TMA v2 · B 站视频脚本与运营包

> **生产总则（先读这条）**
> 1. **所有演示必须真跑**：`/dream`、`a11 → b11`、汇报截图，一律用真实运行画面录制；代码没跑通就不拍，不许拿设计稿/PS 冒充运行结果。
> 2. **不露真实隐私**：demo 数据用自造的"三天聊天样例"，不出现真实姓名、住址、病情、聊天记录截图。
> 3. **数字标"估算"**：成本对比、效果预期，口播和字幕都要带"估算"二字。
> 4. **统一术语**：潮汐忆体 / 双潮 / 年轮链 / 忆死 / 承诺锁，不改词。
> 5. **画幅**：主视频 16:9、1080p 60fps；竖屏版 9:16、1080×1920。封面 1146×717（B站推荐比例 16:10，安全区内放字）。
> 6. **声音**：人声 -6dB 左右，BGM -22dB 以下；字幕用无衬线粗体，底部留安全边距，关键词高亮。
